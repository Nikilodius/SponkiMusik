## ✨ Возможности

- **Поиск музыки** — находите треки через YouTube прямо в приложении.
- **Прослушивание онлайн** — воспроизведение аудио без загрузки музыкальных файлов на компьютер.
- **Моя библиотека** — сохраняйте понравившиеся композиции, создавайте плейлисты и возвращайтесь к истории поиска.
- **Импорт плейлистов** — переносите списки треков по ссылкам из Яндекс Музыки и Spotify; приложение ищет соответствующие композиции на YouTube.
- **Моя волна** — персональная подборка на основе лайков и истории поиска, а также подборки по жанрам.
- **Тексты песен** — просмотр найденных текстов композиций.
- **Эквалайзер и оформление** — настройка звучания и выбор цветовой темы интерфейса.
- **Локальное хранение** — библиотека и настройки сохраняются на устройстве.


## 🚀 Запуск из исходников

### Требования

- Windows 10/11
- Python 3.10 или новее
- Интернет-соединение

### Установка

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/ВАШ-АККАУНТ/Sponki.git
   cd Sponki
   ```

2. (Рекомендуется) создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python app.py
   ```

Либо запустите `start.bat` в проводнике Windows.

## 📦 Сборка .exe

В активированном виртуальном окружении выполните:

```bash
pip install pyinstaller
pyinstaller --clean --noconfirm Sponki.spec
```

Готовая сборка появится в папке `dist/`.

## 💾 Данные пользователя

Лайки, плейлисты и история сохраняются локально в `data.json` рядом с приложением. Этот файл создаётся автоматически при первом сохранении данных. Не добавляйте личную библиотеку в публичный репозиторий — `data.json` уже включён в `.gitignore`.
